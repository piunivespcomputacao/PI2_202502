# 🛠️ GestAir Saúde: Gestão Inteligente da Qualidade de Compressores

## 💡 Sobre o Projeto

O **GestAir Saúde** é uma aplicação web desenvolvida para revolucionar a forma como a manutenção de compressores de ar é realizada em ambientes críticos (hospitais e indústrias).

O sistema simula o processo de inspeção visual manual, mas de forma **automatizada e inteligente**, aplicando regras de diagnóstico sobre os dados de telemetria da peça. O objetivo é **eliminar erros de avaliação humana** e **otimizar a manutenção preventiva**, garantindo a qualidade do ar e a segurança operacional.

O projeto está alinhado com os princípios da **Indústria 4.0**.

---

## ✨ Funcionalidades

O sistema opera como uma ferramenta de **Controle de Qualidade em Tempo Real** para os ativos simulados:

* **Diagnóstico Automatizado:** O usuário insere o ID do compressor e o sistema imediatamente avalia os parâmetros da peça, aplicando regras de negócio para determinar o seu estado.
* **Status de Qualidade:** Retorna um status claro e visual (APROVADO ou REPROVADO).
* **Relatório Detalhado:** Fornece um **diagnóstico específico** que lista todos os parâmetros que estão fora da faixa operacional normal, orientando a equipe de manutenção sobre onde concentrar o esforço.
* **Rastreabilidade:** Permite a consulta rápida e o acompanhamento do histórico de qualidade de peças específicas.

## 🌐 Como Acessar e Utilizar

O **GestAir Saúde** está disponível publicamente para utilização e testes:

### **URL de Acesso:**

[Acessar a Aplicação Web](https://compressoresapp.ddns.net/)

### **Instruções de Uso**

1.  Acesse a URL acima.
2.  Na página inicial, navegue para a área de **Análise de Qualidade**.
3.  No campo de consulta, insira o **ID do Compressor**.
4.  Clique em **"Analisar"**.
5.  O sistema irá exibir o status de qualidade e o diagnóstico completo para o compressor selecionado.
